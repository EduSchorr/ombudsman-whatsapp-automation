## About

The project organizes a workflow that starts with ombudsman/customer-service messages and turns them into structured records, classifications and assisted WhatsApp follow-up.

## What it demonstrates

- Outlook message intake;
- parsing and normalization;
- rule-based complaint classification;
- WhatsApp follow-up preparation;
- local reporting and desktop-oriented workflows.
