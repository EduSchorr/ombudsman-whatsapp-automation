# Automação Ouvidoria + WhatsApp

Fluxo local que transforma mensagens recebidas pela ouvidoria/atendimento em registros estruturados, classificação e acompanhamento assistido via WhatsApp.

## O que o projeto demonstra

- Leitura de mensagens do Outlook;
- extração e normalização dos dados;
- classificação das manifestações;
- preparação do contato via WhatsApp;
- relatórios e fluxo operacional desktop.

## Portfolio Edition

A edição pública usa exemplos sintéticos e não contém caixas de e-mail de produção, dados reais de clientes, credenciais, endpoints privados ou identidade visual corporativa.
